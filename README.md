# 随机点人应用程序 - v3.1

一个使用 PyQt6 开发的跨平台随机点选学生应用程序，现代化 UI + 完整抽取功能。

作者：Leen125 & 杰哥 · 2026

## v3.1 新特性

| 特性 | 说明 |
|------|------|
| 智能加权抽取 | AI 公平算法：被抽中越少的学生，下次被抽中的概率越高（w = 1/(1+次数)），长期保证公平 |
| AI 风格点评 | 每次抽中自动生成一句趣味点评 |
| 语音播报 | 离线 TTS 朗读抽中结果（可选安装 `pip install pyttsx3`，未安装时自动禁用该选项） |

| 特性 | 说明 |
|------|------|
| 现代化 UI | 深色 / 浅色主题一键切换，卡片式界面，圆角 + 渐变按钮 |
| 滚动动画 | 抽取时名字快速滚动并逐步减速，结果带弹性弹出动画 |
| 连抽多人 | 一次抽取 1~20 人，结果同屏展示 |
| 防重复模式 | 一轮之内不重复抽中同一人，抽完全员自动开启新一轮 |
| 缺席管理 | 勾选缺席学生，抽取时自动跳过 |
| 历史记录 | 最近 100 条抽取记录（含时间戳） |
| 统计面板 | 每位学生被抽中次数排行，公平性一目了然，支持一键清空 |
| 内置名单编辑 | 图形界面编辑名单，无需手改 txt |
| 快捷键 | `空格` 抽取 · `Ctrl+E` 编辑名单 · `Ctrl+H` 历史 |
| 数据持久化 | 统计 / 缺席 / 设置 / 历史自动保存到本地 `rsp_data.json` |

## 安装要求

- Python 3.8+
- PyQt6：`pip install pyqt6`
- 语音播报（可选）：`pip install pyttsx3`
- 名单文件 `students.txt`（与程序同目录，每行一个名字；也可以在应用内直接编辑创建）

## 运行说明

```
python RSP.py
```

## 打包

项目附带 `RSP.spec`，可使用 PyInstaller 打包：

```
pyinstaller RSP.spec
```

## 文件说明

| 文件 | 用途 |
|------|------|
| `RSP.py` | 主程序 |
| `students.txt` | 学生名单（每行一个名字） |
| `rsp_data.json` | 运行时自动生成：统计、缺席、设置、历史 |
| `icon.png` / `icons.ico` | 应用图标 |
